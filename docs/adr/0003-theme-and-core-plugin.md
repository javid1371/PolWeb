# ۰۰۰۳ قالب بلوکی و افزونهٔ هسته

وضعیت: پذیرفته. تاریخ: ۲۰۲۶-۱۰-۲۳.

ظاهر با قالب بلوکی `pol-magnetic` است و منطق سایت با افزونهٔ `pol-site-core`. صفحه‌ساز اختصاصی ساخته نمی‌شود.

صفحات بازاریابی برگه‌اند. مقاله‌ها و آموزش‌ها نوشته‌اند. منبع دانلودی بعداً نوع محتوای `pol_resource` می‌شود. مطالعهٔ مشتری برگه می‌ماند.

در این موج نوع محتوا ساخته نمی‌شود.
