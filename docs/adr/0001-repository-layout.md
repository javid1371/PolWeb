# ۰۰۰۱ چیدمان مخزن

وضعیت: پذیرفته. تاریخ: ۲۰۲۶-۱۰-۲۳.

PolWeb مخزن سایت است و از CRM جداست. هستهٔ وردپرس، uploads، `.wp-env/`، `vendor/`، `node_modules/` و `dist/` وارد گیت نمی‌شوند.

کد قابل نصب در `themes/pol-magnetic` و `plugins/pol-site-core` است. `plugins/pol-demo` فقط برای توسعه است و در بستهٔ انتشار نیست.
