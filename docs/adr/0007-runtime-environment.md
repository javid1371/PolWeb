# ۰۰۰۷ محیط اجرا

وضعیت: پذیرفته. تاریخ: ۲۰۲۶-۱۰-۲۳.

بررسی ۲۱ اکتبر ۲۰۲۶ می‌گفت PHP و Composer و WP-CLI و Docker نصب نیستند و `/var/run/docker.sock` نیست. Node آن روز `v22.23.3` و npm `10.9.9` بود. sudo بود.

بررسی دوباره در ۲۳ اکتبر ۲۰۲۶:

- Node `v22.23.4` و npm `10.9.9`. پین `22.23.3` عوض نشد.
- PHP و Composer و WP-CLI و Docker هنوز نصب نبودند. سوکت داکر نبود. sudo بدون رمز کار می‌کرد.
- یک‌بار `php-cli` از مخزن اوبونتو ۲۴.۰۴ نصب شد. کاندیدا `8.3.6` بود و `php8.4-cli` در مخزن رسمی نبود. PPA اضافه نشد. نسخهٔ نصب‌شده: PHP `8.3.6`.
- Docker یک‌بار بررسی شد. `docker` در PATH نیست. `sudo systemctl start docker` شکست خورد چون systemd PID 1 نیست. `sudo service docker start` سرویس را نشناخت. دیمون بالا نیامد.
- wp-env محلی blocked است. پین PHP محیط وردپرس همان `8.4` است.

اثر: lint و test روی PHP 8.3.6 اجرا می‌شوند. فعال‌سازی واقعی وردپرس در این ماشین اجرا نمی‌شود. CI پین PHP 8.4 را جدا نگه می‌دارد.

فرمان رفع مانع، روی ماشینی که دیمون Docker در حال اجراست:

```bash
npm ci
npm run check:integration
```
