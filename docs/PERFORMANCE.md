بودجهٔ ساخت:

- JS اختصاصی صفحهٔ محتوایی حداکثر ۵۰ کیلوبایت gzip
- CSS مسیر نماینده هدف ۸۰ کیلوبایت gzip
- انتقال اولیه بدون ویدئو زیر ۱٫۵ مگابایت

هدف میدانی، جدا از بودجهٔ ساخت:

- LCP صدک ۷۵ حداکثر ۲٫۵ ثانیه

- CLS حداکثر ۰٫۱

دادهٔ میدانی وجود ندارد. اندازهٔ صفحهٔ واقعی هنوز ممکن نیست.
