# POLWEB-003

## مسئله و خروجی

نصب تمیز وردپرس باید قالب و افزونهٔ هسته را بشناسد. خروجی قالب بلوکی، افزونهٔ هسته با نسخهٔ طرح، افزونهٔ demo بدون seed، و تست PHPUnit است.

## محدوده و خارج از محدوده

داخل محدوده: فایل‌های حداقلی قالب و دو افزونه و تست منطق نسخه. خارج از محدوده: بلوک اختصاصی، فونت، فرم، نوع محتوا، صفحه و seed.

## وابستگی

POLWEB-001

## فایل‌ها

`themes/pol-magnetic/`، `plugins/pol-site-core/`، `plugins/pol-demo/pol-demo.php`، `phpunit.xml.dist`.

## معیار پذیرش

قالب Block Theme است و با وردپرس ۷.۱.۳ و PHP ۸.۴ سازگاری اعلام می‌کند. فعال‌سازی هسته option غایب را برابر ۱ می‌گذارد و هنگام غیرفعال‌سازی پاک نمی‌کند. demo در production داده نمی‌سازد. تست سه رفتار نسخه را ثابت می‌کند.

## روش اعتبارسنجی

`npm run test` برای منطق نسخه. فعال‌سازی واقعی با `npm run check:integration`. اگر Docker نباشد نتیجه blocked است، نه fail و نه pass.

## ریسک و بازگشت

مهاجرت واقعی در این موج نوشته نمی‌شود. بازگشت فعال‌سازی، حذف option نیست.
