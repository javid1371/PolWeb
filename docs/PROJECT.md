# پروژه

PolWeb مخزن سایت عمومی پل است، نه مخزن CRM. محصول این موج یک قالب بلوکی و یک افزونهٔ هسته است که روی وردپرس ۷.۱.۳ فعال می‌شوند.

خروجی مرحلهٔ صفر: نسخهٔ ثابت، محیط wp-env، قواعد Cursor، صف کار، و اسکریپت lint و test و package. صفحات بازاریابی و دادهٔ نمایشی در مخزن نیستند.

تصمیم‌های بسته‌شده در `docs/adr/` هستند و تا وقتی ابزار نصب واقعاً شکست نخورده عوض نمی‌شوند.
