---
name: quality-check
description: اجرای lint و test و check-integration و گزارش pass و fail و not-run و blocked
---

این فرمان‌ها را جدا اجرا کن و کد خروج هرکدام را نگه دار:

1. `npm run lint`
2. `npm run test`
3. `npm run check:integration`

برای هر فرمان فقط یکی از pass، fail، not-run یا blocked را گزارش کن. not-run و blocked را pass ننویس. اگر ابزاری نیست، همان پیام فرمان را نقل کن.

نتیجه را در پاسخ بیاور و اگر این بررسی بخشی از یک کار باز است، در فایل شواهد همان کار هم بنویس.
